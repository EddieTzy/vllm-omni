# CosyVoice3 流式 C4 的 padded DiT 编译对照

2026-11-25，RTX PRO 6000 Blackwell Server Edition 96 GB，通用流式 PyTorch Flow + HiFT，talker 采用 FlashInfer，DiT 使用 cuDNN attention。配置差异为模型 config.json 中的布尔值 `cosyvoice3_compile_dit`。上游实现在该后端也会合并 Q/K/V 投影，实测涵盖这一组合行为。

四次独立启动按 A/B/B2/A2 排列，沿用前次 profile 的 4 条英文文本、参考音频和 seed=42，每次 3 波 C4 预热，随后 4 波 C4 测量，共 64 个正式请求。两组使用相同的小量时间戳记录，正式测量关闭 torch.profiler 和 Flow debug。每次启动内用 4 波音频总时长除以 4 波墙钟时长之和计算吞吐。表中最后两列使用每组两次启动的算术均值。

| 指标 | eager 两次启动 | 编译两次启动 | 两组均值 | 变化 |
|---|---:|---:|---:|---:|
| 音频吞吐（音频秒/秒） | 5.311 / 5.087 | 11.790 / 12.420 | 5.199 → 12.105 | +132.8% |
| 平均请求 RTF | 0.674 / 0.694 | 0.245 / 0.237 | 0.684 → 0.241 | -64.8% |
| 平均端到端（秒） | 4.971 / 5.155 | 1.811 / 1.739 | 5.063 → 1.775 | -64.9% |

| 平均末块就绪至最后 PCM（秒） | 3.196 / 3.495 | 0.224 / 0.227 | 3.346 → 0.225 | -93.3% |

| 每个 Euler 步摊销（毫秒） | 26.992 / 28.383 | 6.018 / 5.977 | 27.687 → 5.997 | -78.3% |

收尾按每请求关联 talker 交接层将最终 token 块标记就绪时的单调时钟，与同一主机 HTTP 客户端最后一次非空 PCM read 的时刻。包含提交、排队、后端解码和本地传输。Flow 时长在主机上包围调用，无额外 CUDA 同步，每步为调用总时长除以其 10 个 Euler 步。采样频率 24 kHz，单声道有符号 16-bit 裸 PCM，每请求 RTF 为端到端秒数除以音频秒数。每轮首包 P95 基于 16 个请求，样本量小；语料和并发范围均有限。

[每次启动的指标](results.json) · [编译产物中与 RoPE 相关的调用](compiled-rope.json) · [复现说明](REPRODUCE.md)

四条文本每一轮生成的音频时长均为 8.00、8.72、5.16、9.48 秒。含冷启动编译的第一波 C4 预热，eager 两次为 7.36 / 7.58 秒，编译组为 68.38 / 36.56 秒；两组均剔除了全部预热请求。

另一次独立服务启动中，从真实 C4 请求截取相同的 DiT 输入，分别用原始（合并 QKV 前）权重和编译路径，在预热后各记录一次 estimator forward 的 CPU/CUDA trace。输入 [2,80,450]：设备事件从 1,356（1,334 kernel、22 copy）到 421；输入 [2,80,510]：1,356 到 423。编译代码中每个 block 有一次同时计算 Q/K 旋转的 launch，以及两个包含布局与精度转换的 launch。短 trace 对应的旋转 kernel 在 22 个 block 上各出现一次。这些统计覆盖多个编译器优化；服务收益无法全部归因给 RoPE。保留已有编译路线，当前结果不足以支持另外实现 RoPE kernel。

[输入 450 eager trace](traces/1-eager.json.gz) · [输入 450 compiled trace](traces/1-compiled.json.gz) · [事件与 kernel 计数](trace-counts.json)

3 种实际输入长度 450、510、630，BF16 DiT 输出相对 L2 误差分别约 0.80%、0.72%、0.87%。在诊断服务内复制同一输入状态、恢复 PyTorch RNG 后，逐块比较 20 个流式解码结果（每块均接收该步相同的先前状态）；这与分别积累两个分支状态的完整音频比较有不同口径。首次比较中，波形相对 L2 误差中位数约 1.00。

另一轮独立服务中，每块依次运行两次 eager 和一次编译，固定每次调用开始时的 token、缓存和 PyTorch RNG。20 块（含 4 个终止块）在 eager 重复对照中的最大波形相对误差为 0.00000。编译相对 eager 的逐块相对 L2 中位数分别是 mel 0.78%、STFT 幅度谱 14.12%、波形 98.04%。幅度谱使用 1024 点 Hann 窗、256 点步长。这些是信号误差，尚未做听感或识别质量评测。
